# 克蘇魯的呼喚・調查員檔案室

五個可離線遊玩的繁體中文故事：原作《霧港來信》，以及按年代相連的原創「回聲三部曲」，以及獨立劇院新篇。採CoC第七版核心百分骰機制，由程式擔任單人守密人。

## 2026-10-05：新版電影風格介面與可開關的百分骰動畫

- **遊戲畫面改為單一捲動：**左右地圖與行動面板取消獨立捲軸，內容隨整頁一起移動。縮小標題列與場景橫幅，增加劇情和選項的可見空間。長文視窗開啟時鎖住背景，只捲動正在閱讀的內容；關閉後回到原頁面位置。《霧港來信》只保留內嵌遊戲的頁面捲動，移除外層重複捲軸與標題。
- **必要資訊常駐：**上方固定顯示生命、理智、補給、調查窗口與下一階段；中央提供依劇情狀態更新的「目前目標」。
- **選項就在手邊：**桌面右側列出行動，左側顯示調查員與地圖；任何捲動位置都可使用底部「選擇下一步」與「地圖」。長文、工具與骰子視窗都有固定關閉鈕。
- **行動視窗先看到選項：**期限和補給收成一行摘要，按「查看危機」才展開完整說明，不再讓重複資訊把選項推到下方。
- **重新設計登入、劇本庫與調查場景：**深藍黑底、黃銅色重點、場景大圖、清楚的按鈕與資訊層級。五個故事與既有存檔仍可使用。
- **右上角「顯示設定」：**18／21／24 px 閱讀字級、高對比、全螢幕及「檢定擲骰動畫」。設定會記住，也會同步至《霧港來信》的內嵌遊戲。
- **CoC 百分骰動畫：**用十位與個位 D10 呈現已記錄的檢定；獎懲骰共用個位骰，分別取最低／最高完整結果。顯示技能、門檻、候選值及成功等級；00＋0 正確代表 100。同一行動多次檢定可逐一查看。
- **動畫可略過或關閉：**「略過動畫，查看結果」立即揭示；「關閉之後的擲骰動畫」永久關閉，之後可在顯示設定重新開啟。關閉不影響擲骰判定、存檔或時間，也不會重擲。系統要求減少動態效果時直接顯示結果。
- **高解析度與 Windows DPI：**響應式排版已驗證到 3840 × 2160 CSS 視口；文字、圖示和骰子採可縮放呈現，桌面殼啟用 PerMonitorV2。既有場景插畫為 1536 × 1024，並非新增原生 4K 插畫。
- **快捷鍵：**I 開行動面板、M 開地圖、J 開紀錄。輸入文字或開啟對話視窗時停用，避免誤操作。

可直接開啟 `desktop/dist/Cthulhu-Investigator/Cthulhu-Investigator.exe`；分享時使用 `desktop/dist/release/Cthulhu-Investigator-Windows-x64.zip` 並完整解壓縮。瀏覽器單檔 `Fogharbor-Play.html`／`Cthulhu-Play.html` 也已更新。

## 2026-10-03：Windows 桌面版、危機系統與 62 個事件

**直接開始：**將 `Cthulhu-Investigator-Windows-x64.zip` 完整解壓縮，開啟資料夾中的 `Cthulhu-Investigator.exe`。首次建立本機檔案名稱，選故事，保留預設角色即可出發。Windows 版需要 .NET Framework 4.7.2 以上與 [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；遊戲內容與預設對話均可離線使用。

- **時間會改變局勢：**每個長篇章節預設有 540 分鐘行動窗口。半程錯過聯絡機會並提高警戒；四分之三消耗補給；超時扣支援、提高警戒，且縮短後續章節窗口。最後 180 分鐘撤離緩衝用盡，調查就會結束。终局另有 150 分鐘操作窗口。
- **閱讀不倒數：**查看證物、人物、長文、角色卡或停在背景都不消耗窗口，只有行動會推進。畫面會列出下一階段的剩餘時間和確切代價。
- **62 個事件：**五故事各 10 個專屬事件、12 個共通事件。單一故事有 22 個可能事件，約每 65–110 分鐘出現，當輪不重複。可冒險檢定、消耗補給確保處理，或離開承擔代價；衝突事件失敗會進入戰鬥。
- **補給也需取捨：**歸零會讓玩家調查技能承受一顆懲罰骰。整備能補充，但需要時間；限時聯絡能取得協助，錯過就無法補領。
- **不用再滑到頁尾選分支：**底部常駐「選擇下一步／地圖／推理（或紀錄）」。新行動面板也包含突發事件、限時機會與補給操作；對話視窗的關閉鈕固定保留。
- **五張劇本插畫：**霧港、療養院、列車、退潮古城與劇院各有原創氣氛插畫。解謎資訊仍提供獨立圖形與文字說明。

危機窗口、補給與事件屬於本作自訂情境規則；原有 CoC 核心百分骰、戰鬥與理智機制繼續使用。完整規格見 [CRISIS-SYSTEM.md](CRISIS-SYSTEM.md)。AI 對話仍為離線模式，保留可接模型的介面，未啟用付費服務。

1. 在原本瀏覽器的遊戲按「匯出備份」。
2. 開啟桌面版，在登入畫面按「匯入備份檔案」。

## 長篇玩法

每處地點的主要步驟：

1. **查訪證物**：核心資訊不靠擲骰決定是否存在。
2. **與人物交談**：至少一個主題，也可以問完兩個。
3. **深入調查或慢速核對**：技能成功增加洞見；慢速方法確保推進，花較多世界時間。
4. **選擇立場**：兩個互斥安排影響資源、旗標、支線與結局，不可重選刷資源。

每章完成任三處地點，並在「證物推理」選出正確推論及能支持它的已取得證物，即可前進。早期地點仍可回訪，第四處不因換章永久消失。進入終局後不能回普通地圖。

推論錯誤花10分鐘，不銷毀線索。閱讀角色卡、文件與筆記不耗世界時間。

| 原創資源 | 作用 |
|---|---|
| 支援 | 同伴、工具、急救、確保撤退與終局分工。 |
| 洞見 | 驗證與推理的成果，用於確保終局操作。 |
| 信任 | 當事人對選擇的反應，影響結局、SAN獎勵與下一部合作。 |
| 警戒 | 高警戒提高終局檢定難度；暴露與夜間活動增加警戒。 |

這四項是原創劇本資源，不是CoC官方角色能力。

支線會在對應地點完成某項立場後出現，可回訪處理返家、工資、重逢、更正、住處與保管等問題。部分支線消耗支援，資源不足仍保留另一種方法。

終局有三階段。每階段先閱讀核對依據，再選用2洞見、2支援或技能檢定；前兩者確保完成，檢定承擔失敗風險。三次失誤轉為未完成撤離，也可主動撤離。沒有必須殺死所有敵人的勝利條件。

## 保存與舊版相容

- 一個調查員的五個故事分開儲存，切換不覆蓋其他劇本。
- 每次行動自動保存；不同調查員互相隔離。
- 「匯出整份檔案」包含目前調查員五個故事、筆記、戰鬥中間狀態與結局。
- 「匯入」新增另一份檔案，不覆蓋既有調查員。
- 接受檔案室備份、單部長篇存檔、舊版霧港JSON。
- 若同一儲存空間仍有 fogharbor-save-v1，建立檔案時會嘗試複製進度；不刪原鍵。
- 原作在本機iframe中執行，經來源檢查及格式驗證後同步至目前調查員。
- localStorage不可用時會提醒匯出。換瀏覽器、路徑、裝置或清除資料前，請先備份。
- 不提供多分頁競爭寫入／多人同步或雲端保存。
- Fogharbor-Original.html 保留原作獨立版入口。
